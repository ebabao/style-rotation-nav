一、上一轮因子为什么会错过纳指

上一轮最优是「跌破MA200 且 mom120<0」，但它用 mom120 判断中期趋势，会踩到两个坑：

时点纳指 m60纳指 m120问题
2025-06-30+15.5%−2.7%m60 已强涨，但 m120 还覆盖旧低点 → 被误判走熊、错过涨幅
2019 全年熊转牛MA200 滞后 → 踏空 −9.4pp（上一轮已验证）
根因：m120 是"固定 120 日窗口的净涨幅"，在一波快速反转里，它会同时装着"过去的下跌"和"最近上涨"，方向信号被污染。改用 m250（更长期的净趋势方向）+ MA200（价格位置），反而更干净：纳指 m250 长期为正，m120 的短期扰动被过滤掉了。

三、真实机制：为什么这个因子天然对纳指友好

纳指的走熊判定率只有 6%，是全部资产里最低的——因为它长期上升趋势最稳，m250 转负叠加跌破 MA200 的组合极少在它身上出现。而黄金 21%、沪深300 32%、创业板 36%——越是持续阴跌、趋势反复的资产，越容易被这条规则挡在门外。这不是事后拟合出来的参数，而是"长期趋势方向 + 价格位置"双条件本身的结构属性，正好实现你要的"保纳指、滤阴跌"。
纳指强势期（m60>10%，共 745 个交易日）误伤检查：double 仅误伤 7 天（0.9%），triple 与 ma200_mom120 为 0 天。黄金判定区间：2026-10-21 ~ 11-20 连续走熊，11-09 调仓时 px/MA200=−10.6%、m250=−2.6%，被准确剔除。

五、判断与建议

  • 最优组合因子：double =「价格 < MA200 且 m250 < 0」，在入池时剔除同时满足"跌破长期牛熊线 + 长期净趋势转负"的资产。triple 加 m60<0 更严格但收益略低，double 已是效率最优。
  • 四目标全部达成：挡住黄金 11-09 ✓ / 纳指强势期零误伤（入选 143 次与基线一致）✓ / 2019 不踏空 ✓ / 收益卡玛双升（25.34% / 1.36）✓。上一轮的 ma200_mom120 会误伤纳指+踏空 2019，double 明显更优。
  • 机制真实而非拟合：纳指走熊判定率 6%（最低）、黄金 21%、创业板 36%——长期趋势方向双条件天然对强趋势资产宽容、对阴跌资产严格，这是结构性属性，不是调参调出来的。
  • 但收益提升不可外推：+1.11pp 全靠 2026 一次事件，剔除后与基线等价。定位为"防守型过滤器"而非"收益增强因子"，不要向"年化更高"方向宣传。
  • 建议下一步：① 先以信号层提示运行（标记"某资产已长期走熊、建议下个调仓日剔除"），验证实盘表现；② 若采纳进执行层，double 替换现有 vol_cap 之上叠加，作为第二道过滤；③ 它与每日熔断互补——熔断管组合级急跌，double 管标的级慢性走熊，两者不冲突。
