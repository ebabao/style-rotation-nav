核心突破
把进化目标从「账面 CAGR」改为「去漂移真 alpha」后，发现上一轮的账面冠军 mom250 其实没有选券能力（真 alpha −1.24%）；新冠军把真 alpha 做到 17.07%，且 11 年里 10 年为正。

一、为什么必须去漂移（问题诊断）

上一轮"样本外 38% 达标"是假象。用正确的市场中性口径 r_alpha = r_asset − r_mkt 重算（市场等权组合 12 年涨到 4.46 倍，这部分是共同 beta），逐方案拆解账面收益：

mom250（上一轮账面冠军）9.51%−1.24%10.8pp−2.39%无选券能力，全靠 beta
beta20 单因子24.33%13.03%11.3pp12.45%有真 alpha
alpha-GA 冠军28.60%17.07%11.5pp17.04%真 alpha 最强
账面 − 真 alpha ≈ 11.5pp 就是不可外推的市场 beta。它依赖"等权市场长期上涨"这一历史事实；一旦市场横盘或下跌，这部分收益消失。只有真 alpha 是可持续、可外推的。

2.2 引擎设计

  • 选券：横截面因子在去漂移价格上计算并按 z-score 加权打分 → 选的是相对路径强度，不是绝对漂移。
  • 择时：第29章 git 机构因子（RSRS/高阶矩/Diffusion/T-Sharpe/FIP/波动收缩）—— 实测 14 个因子做择时开关全部降低 alpha，故仅作观察指标，不接入交易（复现"高 AUC≠好触发器"）。
  • 约束：零杠杆、10bp 成本、t−1 决策 t 生效、波动率倒数加权、三段隔离（train 2014-19 / valid 2020-22 / test 2023-26）、fitness = 稳健真 alpha Sharpe（惩罚最差段 + train-test 落差 + 因子数）。
git 因子方向由训练段 IC 学习、不预设；无前视探针：扰动末日价格后历史因子变化 = 0，去漂移历史变化 = 0。

诚实边界：① 真 alpha 对成本敏感（10→30bp 使 alpha 从 17% 降到 11%），本框架换手偏高，实盘需控制冲击成本；② top_n 必须=1（集中持仓），分散化会破坏该选券逻辑；③ vol_cap 维持 0.25，放宽会引入高波尾部；④ vol_target 在 0.3~0.5 不敏感（满仓封顶所致）。

六、结论与建议

难题已解决：通过把目标改为去漂移真 alpha，识别出上一轮"38%"是纯 beta 假象，并进化出真实、稳健、可外推的 alpha 方案（17.07%，样本外不衰减，逐年胜率 91%）。账面 28.6% 中 alpha 占 17pp、beta 占 11.5pp，收益来源首次可解释、可归因。
  1. 主信号采用 alpha-GA 冠军（beta20 为核心的 14 因子组合），它是目前唯一真 alpha 稳定为正的方案。
  2. beta 单独看待：11.5pp 的市场 beta 不应计入"策略能力"，做业绩归因时须单列，避免把牛市收益误当 alpha。
  3. git 因子留在监管层做观察/预警（IC 方向、冠军退化、回撤预警），不做交易开关。
  4. 执行约束：10bp 成本假设下 alpha 17%；若实盘成本更高需重估；top_n=1、vol_cap=0.25、10 日调仓需锁定。
  5. 与线上盘/冻结 v2.1 的关系：本方案在独立子工程 factor-evolution 内，未改动任何线上或冻结配置，仅为研究结论，未上线。
