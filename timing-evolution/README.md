# 择时因子进化学习 · 机构版（timing-evolution）

移植 [ebabao/sr-nav](https://github.com/ebabao/sr-nav) 的 `strategy/evolution_guard.py`
**Q-learning 监管层 + Champion/Challenger 影子台账**范式，应用到 6 ETF 风格轮动的择时因子。

> 本子工程与线上主看板 / all-weather / 每日工作流**完全隔离**，不改动任何线上资产。
> 监管层只记录 / 预警 / 提名，**绝不切换线上冻结 alpha**。

## 一、范式来源与对齐

参考工程 `ebabao/sr-nav` 的机构版方法论（核桃量化《强化学习行业配置》2023-09-22 的可解释落地）：
用「状态 → 动作 → 奖励 → 迭代更新」对抗 **因子 IC 反转 / 模型退化 / 数据滞后**，
但不是黑箱 DQN，而是**表格化 Q-learning 监管层**。

| sr-nav 概念 | 本工程映射 |
|---|---|
| 冠军 Champion（已上线 v1.0） | 冻结 alpha（v2.0 零杠杆冠军，timing=none），逐点净值硬校验 |
| 影子挑战者 Challengers | 围绕冠军的择时参数变体（vol_managed/tsmom/ma_smooth/multi_vote 等 6 个），独立影子回测 |
| State 状态 | 冠军滚动夏普/回撤 + 择时因子已实现 RankIC + 市场 ER |
| Reward 奖励 | 各挑战者相对冠军的滚动夏普超额（风险调整超额） |
| Q 信誉更新 | EWMA：`Q ← (1−α)Q + α·Reward`，表格化在线学习 |
| Action 动作 | argmax Q 提名；连续达标才标 `PROMOTE_CANDIDATE`（仅建议） |
| 监管预警 | 因子 IC 反转（**自适应阈值**）/ 冠军退化 / 回撤预警 |
| Action 治理 | **HOLD 机制**：Q 未过门槛则保持冠军，不硬选挑战者 |
| 晋升约束 | 连续 5 期 + Q 门槛 + 无退化 + 冷却 10 期 |
| 胜率判定 | **风险调整口径**（Sharpe/Calmar），非单一 CAGR |
| 闭环验证 | 按 Q 提名真实切换的累计净值 vs 冠军（可验证依据） |
| 影子台账 | 影子净值 / 影子台账 / 监管事件 / 信誉Q演化 CSV |

## 三、机构版核心设计

### 1. 冠军不变 + 影子挑战
冻结 alpha 逐点校验（diff=0）后才建立影子台账；6 个择时变体独立回测，
只记录虚拟净值，不影响冠军。这是"冠军-挑战者"治理的核心——**学习不等于上线**。

### 2. 零前视的已实现 IC
择时 regime 因子为市场级时序信号（时序动量 / 低波状态 / 趋势效率 ER）。
IC 只用 `d+h ≤ t` 的 (信号@d, 未来h日组合收益@d) 配对，全部在评估日前已实现。
核心监管信号 `mkt_er`（趋势效率）长期 IC≈+0.09，跌破 −0.02 判为因子反转。

### 3. EWMA 信誉 Q + 晋升治理（v3.1 优化）
```
Q[n] ← (1−α)Q[n] + α·(夏普[n] − 夏普[冠军])      α=0.30
best = argmax Q
leader = best  if  Q[best] > 0.05  else  冠军(HOLD)   # 治理修正
晋升候选 = leader 非冠军 ∧ 连续5期领先 ∧ Q>0.05 ∧ 无退化 ∧ 冷却期结束
```
每 20 交易日评估一次，共 156 期；晋升仅记录，不自动切换。
**HOLD 机制**是关键治理修正：多数期挑战者 Q 为负，若仍硬选挑战者会造成无谓切换；
改为 Q 未过门槛即保持冠军，影子切换收益因此从 25.4% 回升到 29.3%。

### 3b. v3.1 三处实质优化
1. **IC 反转自适应阈值**：固定 −0.02 在 IC 标准差 0.36 下误报率 36%；改为按已实现 IC
   历史 10% 分位数（夹在 [−0.35, −0.02]）动态定阈，预警率降至 26.9%，预警更有信息量。
2. **胜率判定改风险调整口径**：单一 CAGR 口径下 0 个挑战者胜出；按 Sharpe/Calmar
   口径有 5 个胜出（低波温和/趋势跟随/均线平滑/多投票/软仓）——正确反映择时"以收益换风险"的价值。
3. **影子切换闭环验证**：真实模拟按 Q 提名切换的累计净值，与冠军对比给出可验证依据。

### 4. 三段进化（可选辅助）
`timing_learn.py` 保留了一版离线 GA 三段进化（train/valid/test + 收益封顶反套利 +
champion/challenger 版本化 + 递归测试零前视探针），作为参数研究工具，非机构版主线。

## 五、本次运行结果（v3.1，2026-11-21）
- 冠军逐点校验差 **0.00e+00**；156 期评估（2014-01 ~ 2026-10）
- IC 反转 **42 次（26.9%，自适应阈值）**、晋升候选 10 次、冠军退化 16 次
- 收益口径跑赢冠军 0 个；**风险调整口径跑赢 5 个**（HOLD 治理下末期 leader = 冠军）
- **影子切换闭环**：Q提名组合 CAGR 29.27% / MDD −21.76% / **Sharpe 1.8640**（Δ+0.0365 vs 冠军 1.8275），
  目标夏普 1.74 **达标**，目标回撤 18.39% 未达；切换 28 次、HOLD 占比 32.7%
- 结论：择时以收益换夏普/回撤，监管层如实提名而不切换；闭环验证给出"提名组合风险调整占优"的可核验证据。

## 六、第29章 GitHub 择时因子（真正的机构版择时因子，2026-11-21）
按资料库文档第29章落地，14 个市场级因子（7 大类），逐条标注 GitHub/论文来源，零前视。

| 环节 | 结果 |
|---|---|
| 单因子 OOF AUC | **fip252=0.674 最强**；diffusion_div 0.587、diffusion20 0.580；**RSRS≈0.501 被证伪**（与文档一致） |
| 干净时间外（训练13-21→测试22-26） | fip252 **0.716**、m5_z 0.816；GitHub新因子6 **0.672 > 现有 0.566** |
| 跨阈值稳健（−10/−6/−8% 全>0.55） | 仅 **fip252、diffusion20** 全稳；m5_z 时间外高但不稳（防过拟合） |
| **29.3 高AUC≠好触发器** | fip252 当避险开关：年化 **32.77%→25.25%（崩 7.5pp）**，回撤 **−19.54% 完全没变**——只削收益不降回撤 |
| 29.4 采纳 | fip252/kurt20/diffusion20 纳入**监管观察指标**+ML 输入，**不**当开关；只提名不切换 |

关键教训：fip252 是"趋势平滑度/拥挤度"因子（IC 为正，平稳上涨后续涨），
当避险开关会在主升浪反复误报切掉盈利仓——**"统计上预测下跌概率高"≠"应现在减仓"**。
配置见 `v3.2第29章择时因子观察指标配置.json`；报告见 `第29章GitHub择时因子研究报告.html`。

## 七、诚实性边界
