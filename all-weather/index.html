自动化同步与部署

每日由定时任务运行 sync_daily.py：抓数 → 模型回放 → 生成 data/ 接口 → 写入同源发布目录（实时目录映射，写入即线上生效）。本页为静态文件，通过 fetch(..., {cache:"no-store"}) 读取最新接口，因此页面无需重建即可每日同步， 策略模型接口与看板页面数据始终同源。仓库内另备 GitHub Actions 工作流 （daily_sync.yml + watchdog.yml），推送到有写权限的仓库后可在 GitHub Pages 上以同一套接口自动部署与停更重启。
